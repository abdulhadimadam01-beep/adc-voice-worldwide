# ADC VOICE WORLDWIDE — PWA starter

Wannan shi ne farkon samfurin app na ADC Voice Worldwide. Yana aiki a matsayin installable PWA a Android da iPhone idan an wallafa shi a HTTPS hosting.

## Abin da ke ciki
- English/Hausa language switch
- Responsive mobile-first interface
- PWA manifest da app icons
- Service worker domin cache/offline shell
- Sassan Latest News, ADC Updates, Nigeria Politics, Gallery da About

## Yadda za a wallafa shi kyauta
1. Kirkiri GitHub account a https://github.com/
2. Kirkiri public repository mai suna `adc-voice-worldwide`.
3. Upload dukkan fayilolin da ke cikin wannan folder.
4. Kirkiri Cloudflare account a https://dash.cloudflare.com/
5. Je zuwa Workers & Pages > Create > Pages > Connect to Git.
6. Haɗa GitHub repository din, ka zaɓi main branch. Build command a bar shi babu komai; output directory ya zama `/` ko `.` bisa dashboard.
7. Bayan an wallafa, za ka samu adireshin `*.pages.dev`.

## Saka app a waya
- Android: buɗe adireshin a Chrome, zaɓi Install app ko Add to Home Screen.
- iPhone: buɗe adireshin a Safari, Share > Add to Home Screen.

## Muhimman iyakoki
Wannan prototype ne. Labaran da ke ciki misalai ne, ba sabbin labarai na gaske ba. Ba a haɗa database ko online admin dashboard ba tukuna; canje-canjen da aka yi a source code ne za su sabunta shafin. Push notifications, real-time editorial workflow da store publishing suna buƙatar ƙarin saituna. Kada a wallafa sanarwa ko labari a matsayin hukuma sai an tantance shi kuma an samu izinin da ya dace.

## Branding
Launuka: Green, White, Orange. An saka ainihin ADC Voice Worldwide logo da mai amfani ya bayar a header da app icons.
